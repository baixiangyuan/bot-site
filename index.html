部署方式

Linux 部署

git clone https://github.com/xiaoyaya191/bilibili_learning_bot.git cd bilibili_learning_bot pip3 install -r requirements.txt python3 new_agent.py

Windows 部署

git clone https://github.com/xiaoyaya191/bilibili_learning_bot.git cd bilibili_learning_bot pip install -r requirements.txt python new_agent.py

Android 部署

# 打开 Termux 终端应用 pkg update && pkg install git python ffmpeg -y git clone https://github.com/xiaoyaya191/bilibili_learning_bot.git cd bilibili_learning_bot pip install -r requirements.txt python new_agent.py

Docker 部署

git clone https://github.com/xiaoyaya191/bilibili_learning_bot.git cd bilibili_learning_bot docker compose up -d

视频理解模式

模式原理速度适用场景
subtitle标题+简介+字幕+评论⚡ 极快知识类视频
framesffmpeg抽帧+视觉模型🐢 较慢教程/演示
hybrid字幕+抽帧综合分析🐢 慢全面理解

心理画像引擎

通过 L1表层兴趣 到 L5演变趋势 五层递进模型进行分析。自动生成惊喜探索和趋势推荐内容，杜绝枯燥重复的单一推送。

知识库系统

视频评分超过预期设定后自动分类归档，并可触发知识验证与联网搜索，帮你一键整理出专属的高价值资料。按 O 可一键自动重构整理。

快速开始

{ "api": { "unified_api_key": "sk-你的APIKey", "unified_base_url": "https://api.openai.com/v1" } }

修改完配置后，通过 python web_panel.py 即可在网页端扫码登录与实时观测。

安全说明与规范

切勿将 Data/config.json 以及 Data/bilibili_cookies.json 分享给他人。开启干运行能够完美在不留下真实点赞记录的情况下调试 AI 的逻辑状态。
